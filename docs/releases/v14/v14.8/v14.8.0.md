This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add a generic `pyproject-lint-ci` workflow and move the Zizmor checks there.
  - `pdm run lint` is now expected to cover both pyproject format checking and Zizmor linting in all repositories.
  - I think this is the better way to do it because if we ever extend our Python linting, it will already be accounted for without me needing to also restructure the workflows.
- Restructure actions-ci into a separate check for the lockfile and actionlint.
  - Better separations of concerns and allows them to run in parallel.
