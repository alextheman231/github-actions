## Description of Changes

<!-- user-editable-section-start -->
- Remove the registry URL input to `actions/setup-node` in `npm-registry-publish` workflow.
  - It is the default when using `actions/setup-node` and it may be causing a constant warning in the actions logs about being unable to resolve the NODE_AUTH_TOKEN, which is not there anyway due to the OIDC configuration.
