## Description of Changes

<!-- user-editable-section-start -->
- Migrate the commit-changes composite action to the TypeScript actions setup
  - To keep it consistent with all the other composite actions and make the logic read nicer than it would in Bash.
  - To migrate existing usages, replacing all references to `alextheman231/github-actions/.github/actions/commit-changes` with `alextheman231/github-actions/composite/commit-changes`.
  - The `changes_detected` output has also been converted to kebab-case, so it will now be referred to as `changes-detected`.
