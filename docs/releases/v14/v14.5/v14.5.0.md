This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Migrate the commit-changes composite action to the TypeScript actions setup
  - To keep it consistent with all the other composite actions and make the logic read nicer than it would in Bash.
  - To migrate existing usages, replacing all references to `alextheman231/github-actions/.github/actions/commit-changes` with `alextheman231/github-actions/composite/commit-changes`.
  - The `changes_detected` output has also been converted to kebab-case, so it will now be referred to as `changes-detected`.
- Remove hard reset after updating actions from `update-dependencies`.
  - No longer needed as we control actions updates with `actions-up` and `gh actions-lock`, neither of which are likely to cause extraneous changes as of now. Extraneous changes were only really brought about with PNPM.
- Label the dependency updates as low risk automatically.
  - Rather than solely relying on add-risk-label to be present on the workflow.
    It saves time and saves us from an initial redundant failing check-labels workflow.
