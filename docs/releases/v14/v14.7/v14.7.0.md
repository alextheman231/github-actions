This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Restructure `actions-ci` so that this repository can use it too
  - This will mean that we need to refactor every other repository to run PDM so it can install Zizmor, but I think it'll be worth it.
  - Installation from lockfile is generally preferred where possible, and since Zizmor is currently failing in several places when we update this action I think it's worth changing now.

## Additional Notes

- I have decided this is a minor change because despite technically being breaking, it is an internal reusable workflow rather than part of the public export interface.
- In my view, from now on, any composite action that you can reference from `alextheman231/github-actions/composite` is to be considered stable and usable by other consumers, whereas anything in `alextheman231/github-actions/.github` is internal to this organisation and is subject to change.
