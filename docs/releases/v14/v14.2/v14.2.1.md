## Description of Changes

<!-- user-editable-section-start -->
- Add usage of `gh auth setup-git` to configure the GitHub bot user in `configure-github-bot-user`
  - This should allow the bot to push to GitHub in subsequent steps.
- Add extra `pull-request-number` and `pull-request-branch` outputs to `update-dependencies`
  - So the updates in this repository can ~~regretfully~~ reference these to make some further changes after putting up the pull request.
  - You know, such as committing raw build outputs like a caveman! I seriously hate that I have to do that...
