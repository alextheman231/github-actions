This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add a `configure-github-bot-user` composite action to centralise how we configure the GitHub bot user.
  - If we do it manually every time there are so many potential places for drift with the app slug etc.
  - As such, best to centralise it into a single composite action and just use that to ensure that the GitHub bot user is correctly configured every time. This is needed to ensure that any commits made are associated with the bot user.
<!-- user-editable-section-end -->
