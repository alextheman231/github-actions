This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add `secret-scan-ci` workflow to scan for secrets per repository.
  - This is expected to run on pull request creation and scan for the presence of any leaked secrets on the pull request.
  - It replaces the default GitGuardian Security Leaks workflow that GitGuardian provides us already, giving us more control over our workflows.
