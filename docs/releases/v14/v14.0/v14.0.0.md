# v14.0.0 (Major Release)

**Status**: Released

<!-- alex-c-line-release-summary-start -->
This is a new major release of the `github-actions` package. It has the potential to introduce breaking changes that may require a large amount of refactoring. Please read the description of changes and migration notes below for more information.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add new `get-package-metadata` composite action to get the name and version from `package.json` easier in GitHub Actions workflows.
- Remove the version checks from `npm-registry-publish` and `create-github-release`
  - The existing check in `npm-registry-publish` is now its own reusable workflow at `report-npm-version-existence`.
  - The two existing checks in `create-github-release` are now `report-version-tag-existence` and `report-release-note-existence`.
  - These have been separated out to give callers more control over exactly which checks should pass before publishing.

## Migration Notes

- For `npm-registry-publish` replace:

```yml
jobs:
  npm-registry-publish:
    permissions:
      id-token: write
    uses: alextheman231/github-actions/.github/workflows/npm-registry-publish.yml@v13.0.2
```

with:

```yml
jobs:
  report-npm-version-exstence:
    permissions:
      contents: read
    uses: alextheman231/github-actions/.github/workflows/report-npm-version-existence.yml@v14.0.0

  npm-registry-publish:
    needs: [report-npm-version-existence]
    if: ${{ needs.report-npm-version-existence.outputs.version-exists == 'true' }}
    permissions:
      id-token: write
    uses: alextheman231/github-actions/.github/workflows/npm-registry-publish.yml@v14.0.0
```

- For `create-github-release` replace:

```yml
jobs:
  create-github-release:
    if: ${{ github.repository == 'alextheman231/alex-c-line' }}
    uses: alextheman231/github-actions/.github/workflows/create-github-release.yml@v13.0.1
    with:
      node-version: 26
      CLIENT_ID: ${{ vars.ALEX_UP_BOT_CLIENT_ID }}
    secrets:
      APP_PRIVATE_KEY: ${{ secrets.ALEX_UP_BOT_PRIVATE_KEY }}
```

with:

```yml
jobs:
  check-version-tag:
    permissions:
      contents: read
    uses: alextheman231/github-actions/.github/workflows/report-version-tag-existence.yml@v14.0.0
    with:
      CLIENT_ID: ${{ vars.ALEX_UP_BOT_CLIENT_ID }}
    secrets:
      APP_PRIVATE_KEY: ${{ secrets.ALEX_UP_BOT_PRIVATE_KEY }}

  check-release-note:
    permissions:
      contents: read
    uses: alextheman231/github-actions/.github/workflows/report-release-note-existence.yml@v14.0.0
    with:
      CLIENT_ID: ${{ vars.ALEX_UP_BOT_CLIENT_ID }}
    secrets:
      APP_PRIVATE_KEY: ${{ secrets.ALEX_UP_BOT_PRIVATE_KEY }}

  create-github-release:
    permissions:
      contents: write
    needs: [check-version-tag, check-release-note]
    if: ${{ needs.check-release-note.outputs.release-note-found == 'true' && needs.check-version-tag.outputs.tag-exists == 'true' }}
    uses: alextheman231/github-actions/.github/workflows/create-github-release.yml@v14.0.0
    with:
      CLIENT_ID: ${{ vars.ALEX_UP_BOT_CLIENT_ID }}
      tag: ${{ needs.check-version-tag.outputs.tag }}
      release-note-path: ${{ needs.check-release-note.outputs.release-note-path }}
    secrets:
      APP_PRIVATE_KEY: ${{ secrets.ALEX_UP_BOT_PRIVATE_KEY }}
```
