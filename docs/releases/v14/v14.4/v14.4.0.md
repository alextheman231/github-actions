**Status**: In progress

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Migrate all workflows to pin references by tag in the source, and then SHA pins are done in the lockfile.
  - This is now possible thanks to `gh actions-lock`.
- Change `update-dependencies` to account for the actions lockfile.
  - So that after updating all the tag references, we then also update the lockfile.
  - If dependency updates fail as a result of this change, you will most likely just need to run `gh actions-lock` in the repository to migrate the workflows to use the lockfile. You may also need to disable `unpinned-uses` from Zizmor because it doesn't yet recognise the actions lockfile.

## Additional Notes

- I have been wanting this for literally ages now, and now the dream is finally here!
- It's not perfect yet - we still need to update the tags manually first as the CLI doesn't support updating the tags themselves yet, but it is a start and it's better than nothing.
- This will be the new ideal way to manage actions dependencies going forward, especially when/if they add support for updating the tag references and the lockfile in one go.
