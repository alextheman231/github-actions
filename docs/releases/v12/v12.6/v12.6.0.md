This is a new minor release of the `github-actions` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add a workflow to check that at least one label has been assigned to pull requests in a given repository
  - All pull requests should have labels categorising the type of change they are aiming to make.
  - It makes it easier when searching through pull requests so we can filter them depending on the category of change they are making.
