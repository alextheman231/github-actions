This is a new patch release of the `github-actions` package. It includes small, non-breaking changes and should require no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Change the policy behind `check-labels` slightly.
  - The requirement now is that pull requests should have at least one risk label and one category label.
  - Priority labels do not count as either and will not contribute anything towards the action passing or failing. That is, priority labels are optional.
  - The above changes will ensure that every pull request identifies a risk level and the type of change it is aiming to make.
