## Description of Changes

<!-- user-editable-section-start -->
- Exit 0 in `add-risk-label` if the pull request template doesn't have a risk level
  - This will be needed for things like the change request workflow, where the template used is the change request itself.
- Label change requests as medium risk
  - As they will most likely depend on a change outside the pull request, they should not be considered low risk.
